# LEVEL 2

## Archivos nombrado con espacios
Nombres como `archivo con espacios` al usar cat este los toma como varios argumentos. 

```bash
# Ejemplo 
cat archivo con espacios
```

Forma correcta de trabajar con ellos es con comillas.
```bash
# Ejemplo 
cat "archivo con espacios"
```

Otra forma es usar "\"
```bash
# Ejemplo 
cat archivo\ con\ espacios"
```
