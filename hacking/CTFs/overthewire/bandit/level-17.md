# LEVEL 17

## Diferecia de archivos 
Este reto es de análisis comparativo.

Nos presenta dos archivos distintos que parecen idénticos, el uso del comando `diff` nos va ayudar a comparar el contenido de dos archivos y muestra qué líneas se han añadido, eliminado o modificado.

Uso básico:
```bash
diff archivo1 archivo2
```
Salida:
```bash
< vieja_linea
---
> nueva_linea
```
  * `<` = línea en archivo viejo
  * `>` = línea en archivo nuevo
