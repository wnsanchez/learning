# LEVEL 4

## Buscar un archivo legible
Usaremos el comando `file` como analizador ya que este no se basa en la extensión.

Se basa en bytes iniciales del archivo, shebang, firmas internas


Como usar:
file [opciones] archivo

Ejemplo de uso en directorio con varios archivos:

```bash
file ./-archivo0*
```

> Archivo legible: ASCII text
